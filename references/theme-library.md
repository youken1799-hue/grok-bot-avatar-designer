# 历史主题与建议视觉系统

以下来自用户曾经提出的 Bot 头像设计方向，以及针对“同质化严重”提出的设计调整。名称是主题标签，不代表官方品牌命名。

| 主题 | 主色建议 | 核心元素 | 机器人差异化动作/构图 | 避免 |
|---|---|---|---|---|
| Asobi / 游戏 | 鲜蓝、青蓝 | PS5 DualSense 风格白黑手柄 | 机器人双手握手柄，斜向动态构图 | 通用旧式游戏手柄、复杂星空 |
| Cripy / 投资 | 金橙、深蓝 | Bitcoin 符号 / 金币 | 头部近景 + 单枚币，局部几何行情线 | 密集 K 线、满屏光圈 |
| Kaji / 家务 | 薄荷绿、暖黄 | 扫帚 + 计算器（用户曾要求由笔改成计算器） | 侧身拿扫帚、另一手展示计算器 | 三种以上工具堆叠 |
| Kau / 购物 | 焦糖棕、爱马仕橙 | 购物袋、H / LV 主题标识 | 机器人坐在购物袋旁/探出袋口 | 多个大型 Logo 重叠 |
| Kids / 儿童 | 彩虹、暖粉、浅蓝 | 星星、彩虹、积木式 Kids 字样 | 云朵中探头、张开双臂 | 太多发光小星星与大文字 |
| Manabi / 日语学习 | 富士蓝、樱花粉 | 平假名书本 / 富士山 | 机器人翻书、指向一个清晰平假名 | 多字符错误、符号过密 |
| Miru / 影视 | Netflix 红、黑 | 红色 N / 播放三角 | 机器人从 N 形负空间里出现 | 强烈仿冒官方头像 |
| Moomoo / 证券 | 活力橙、白 | 牛角剪影/品牌牛形 | 头盔轮廓融入牛角 | 把牛角直接粗糙叠在脸上 |
| 日本城市与宠物 | 樱花粉、东京红、天蓝 | 柴犬、东京塔、晴空塔、樱花 | 机器人与柴犬并肩；地标精简为剪影 | 同时塞入富士山、双塔、摩天轮等 |

## 曾有的精确修改偏好
- 日本主题头像：移除计算器，右下角加入晴空塔；之后再移除富士山，其他元素保留。
- Astro Bot 蓝色头像：改变背景，手柄明确为 PS5 风格。
- Netflix Bot：除红色 N 外一定要有明显机器人元素。
- 多款旧头像：原先背景有霓虹光环、复杂场景，用户希望更简洁、更容易记忆，不要只换手中道具。
- 品牌主题头像：兼顾 Logo 辨识度与机器人造型，而不是单纯复制 Logo。

## 整组设计的推荐控制方式
提前给每一款分配独立的：主色、核心道具、表情/动作、画面结构。系列可使用相同的细线条/圆角/轻 2.5D 光影，但不要采用完全相同的姿势。
